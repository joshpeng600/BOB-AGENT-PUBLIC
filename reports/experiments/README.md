# Experiment reports

Human-readable validation experiment reports. Each report must identify its manifest and complete producing commit SHA.

The compact repository-wide table is [`../experiments.csv`](../experiments.csv).
Its formal rows are transcribed from merged independent E evidence; decision,
baseline, delta, and `test_access` facts remain visible in the `recovery` field
without changing the established CSV schema used by `tools/summarize_experiments.py`.
